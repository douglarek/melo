# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version or commit, the platform (macOS or Linux), reproduction steps, and any relevant logs with credentials removed.

Do not open a public issue for a security problem. Reports about the YouTube or LRCLIB services themselves should go to those providers.

## Scope

In scope: the Melo source code, login and cookie handling, local session and cache storage, external command invocation, and the build/release configuration.

Out of scope: vulnerabilities in YouTube, Google, LRCLIB, the operating system, or other third-party services and binaries.
